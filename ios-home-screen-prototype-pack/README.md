# iOS 桌面主屏原型 · 打包说明

本文件夹包含完整的 **Skill 文档 + 可交互原型**，可直接使用或作为 WorkBuddy Skill 安装。

## 文件

| 文件 | 说明 |
|---|---|
| `SKILL.md` | Skill 文档：功能清单 + 完整移动规则（排序 / 相邻互换 / 实时布局 / 跨页 / 多选 / 原子落位 / 前面无空格 / 交互机制）+ 定制参考 |
| `ios-home-screen.html` | 可交互原型（单文件、零依赖），浏览器直接打开即可使用 |

## 快速开始

```bash
open ios-home-screen.html        # macOS 直接打开
# 或把该文件拖入浏览器
```

或作为 WorkBuddy Skill 使用：将本文件夹放入 `~/.workbuddy/skills/`，然后在对话中要求"生成 iOS 主屏原型"即可。

## 原型包含的能力

- **4×6 网格**桌面，1×1 / 1×2 / 2×1 / 2×2 / 4×2 组件，3 页默认数据
- **完整移动规则**：1×1 严格排序且前面无空格、相邻 1×1 直接互换、大→小 / 小→大 / 同尺寸互换
- **跨页必成功**：目标页放不下就把被挤元素挤出到后一页，后一页也满则**新建一页**承接（不再"空间不足拦截"）
- **拖动反馈**：单选拖动其他元素不动（松手一次性落位）；多选拖起即由 1×1 实时补位
- **多选拖动**：长按 / 按钮进入，leader 规则，集合**整组连续插入**，放不下的放回原页
- **原子落位**：失败零副作用，不丢元素
- **右侧规则面板 + 操作日志**：实时反馈命中的规则分支

## 规则来源

《OS 桌面元素移动（究极版）》Xmind。其中「排序开关」（开启=顺位排序 / 关闭=Google 默认排列）
与文件夹/叠加成组未实现，原型固定为顺位排序模式。
