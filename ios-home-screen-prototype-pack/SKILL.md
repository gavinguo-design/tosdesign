# iOS 桌面主屏原型（手机首页布局）

## 概述

生成一个完整、可交互的 iOS 风格桌面主屏原型，单文件 HTML、零依赖、无构建步骤。
包含 iPhone 外壳（340×700，圆角 54）、状态栏、壁纸、应用网格（4×6）、Dock、分页点、
多页状态、多选模式、右侧实时规则判定面板与操作日志——以及完整的拖拽 / 排序 / 互换 /
实时重排 / 跨页 / 原子落位逻辑。

## 使用场景

- 用户需要一个 iOS 主屏 / 桌面 / 应用网格原型或高保真交互稿
- 需要在网站测试或 UI 走查中嵌入可交互的 iPhone 主屏
- 需要演示桌面图标拖拽、自动补位、大小组件互换、跨页拖动
- 需要展示"1×1 严格排序"、"相邻互换"、"实时布局变更"等桌面元素移动规则

## 使用方法

1. 将 `ios-home-screen.html` 复制到目标目录（文件完全自包含，浏览器直接打开即可）
2. 用 `present_files` 打开该 HTML（内建预览面板实时展示）
3. 需要调整时，按下方"定制参考"修改常量 / CSS / 脚本

## 功能清单

### 交互能力
- **拖拽**：任意元素按住拖动，滞回取格（边界微动不抖动，快速拖动跟手）
- **多选**：长按 450ms 或点"多选模式"按钮进入；点击图标切换选中（保序 + 黄色序号徽标）；点击空白退出；拖动任意已选元素整体移动集合
- **跨页**：拖到屏幕左/右边缘停留 420ms 翻页；目标页空间不足则拦截并提示；原页 1×1 自动补位
- **增删**：工具栏可新增 1×1 / 1×2 / 2×1 / 2×2；删除后 1×1 自动补位
- **规则面板**：右侧实时显示命中的移动规则分支（空白/同尺寸/大→小/小→大/多选）
- **操作日志**：记录每次移动/补位/跨页/放回/失败还原

### 动效与反馈
- 拖动元素放大 + 描边阴影；集合拖动轻微缩放半透明
- 占位框呼吸动画；非法落点红色高亮；落位弹跳（dropBounce）
- 跨页边缘高光提示；新页元素淡入
- 位置变化实时平滑过渡（CSS cubic-bezier）

## 完整规则（严格实现）

### 一、排序规则
| 元素 | 规则 |
|---|---|
| **1×1** | 严格从左到右、从上到下排序；1×1 之间不允许空隙（reflow 自动补齐，序号连续） |
| **非 1×1** | 位置相对固定，不参与自动排序；可自由拖放，允许空隙 |

- 补位不跨页，仅排序当前页面元素
- **1×1 自动排序严格"前面无空格"**（reflow / placeAtFixed 填充）；**拖动松手固定场景例外**：1×1 拖到空白松手时**固定当前位置不变**，其他 1×1 基于排序填充剩余空格（优先填 dragged 前面的空格、再填后面）；若其他 1×1 不足以填满其前面的空格，则允许 dragged 前面留空（用户主动放置的语义，不再降级弹回）

### 二、移动场景（判定优先级 A → B → C → D）
**A. 目标格空白**
- 1×1 → 松手后**固定当前位置**，其他 1×1 基于排序填充剩余空格（优先填满 dragged 前面的空格）
- 非 1×1 → 直接放置；松手后空隙由 1×1 补齐

**B. 同尺寸互换**
- 1×1 → **相邻（上下左右，曼哈顿距离 1，不含斜对角）直接互换位置与 order**；不相邻走插入补位排序
- 非 1×1 → **目标相邻方向有空隙则沿方向平移一格让位（多空隙优先反方向）；无空隙直接交换**（E 回到被拖元素原位）

**C. 大 → 小**（大元素可完整覆盖小元素区域）
- 无论空满屏均可直接移动；落位后被挤压的**所有元素（含 1×1 与非 1×1）**挪到空位（大块优先放置）；1×1 重新排序

**D. 小 → 大**
- 被压大元素水平/垂直方向有足够空隙才可让位（优先拖入方向的反方向）；无空位则**禁止移动**

**从当前页移走（跨页）**：留下的空位由本页其他 1×1 自动补位
**从其他页移进来**：位置不足禁止移动；目标为空可直接放置；占据 1×1 → 被占者依次后移；占据非 1×1 → 有空位让位，无空位则 1×1 落到页面上 1×1 空位 / 非 1×1 无法移动

### 三、多选拖动（基于体验完善）
- 进入：长按 450ms 或按钮；选择：点击切换（保序 + 序号徽标）；退出：点击空白
- **仅 1×1 元素可加入多选**（截图规则；点击非 1×1 提示"仅 1×1 元素可多选"）
- 拖动：按住任意已选元素，集合整体跟手（锚点跟手、其余保持相对像素偏移）
- **规则判定基于首个选中（leader）的尺寸**（A→B→C→D 复用；多选落位禁用相邻互换 noSwap——集合语义走插入/排序，避免 swap 目标格被补位占用失败）
- 落位：leader 按单元素规则落位 → 其余按选择顺序从 leader 位置**依次紧密排列**占满目标页空隙（orderedCells 行优先）→ **放不下的放回原页**（跨页回原页 reflow；同页留在本页找空位）（日志提示 N 个放回）
- **落位后 `renumberOrders` 按行优先重排各页 1×1 order**（rest 排列后 order 保持旧值会重复/空洞 → 后续拖动错乱，必须重排）
- 跨页：集合整体移动，目标页需能放下 leader 才允许翻页

### 四、实时布局变更（iOS 式实时预览）
- 拖动元素固定在当前格；**空出区域由其他 1×1 实时补位**（不等松手）
- 每次目标格变化即重算布局：**快照重建输入**（snapMap，位置与 order 全取拖动前快照）保证连续拖动稳定不漂移
- 实现：`liveLayoutFor` = 快照重建 + `attemptMove`（挤压/互换/大小让位）+ `placeAtFixed`（dragged 固定当前格，其余按 order 补位填充）

### 五、原子落位（多选 / 失败零副作用）
- `multiPlace` 在**克隆的 simPages** 上完整模拟（移除集合 → leader 落位（noSwap）→ rest 紧密排列 → 放不下的放回原页 → **renumberOrders 重排各页 order** → 全量校验无重叠无未放置），**通过后才应用到真实 pages**
- 失败时 pages 不被破坏，配合 pagesSnapshot 整体还原——不会丢元素、不会卡死

### 六、交互机制（体验层）
1. **滞回取格 snapGrid**：|delta|≥1.5 直接取整保持跟手；否则越过格线 0.6 才切换（死区 0.4~0.6），边界微动不抖动
2. **RAF 节流**：仅目标格变化才重排，动画不被频繁打断
3. **跨页动效**：边缘高光 + 停留 420ms 翻页；非法跨页红色提示拦截
4. **视觉反馈**：占位框呼吸、非法红色高亮、落位弹跳、拖动放大描边
5. **操作日志**：每次操作实时记录（成功/失败/跨页/放回/还原）

## 定制参考

- **布局常量**（`<script>` 顶部）：`COLS`、`ROWS`（默认 4×6=24 格）、`CELL`（54px）、`GX`/`GY`（列距 14 / 行距 20）、`PAD`
- **手机壳 / 壁纸**：`.phone`（340×700，圆角 54）、`.screen`（4 色壁纸渐变）
- **元素类型**：`TYPES` — `1x1`、`1x2`、`2x1`、`2x2`；工具栏可增删
- **配色**：`PAL` 渐变对数组；**角标**：`e.badge`（红底白字）
- **Dock**：`.dock`（280×76，圆角 34，4×54×54 图标）
- **初始数据**：修改 `seed()` 函数（底部）可自定义 3 个默认页面
